# Models

Copy these files to the folder from which the pipeline and `comparison/compararReducao.py` are run.

**Sensor classifier**

- `model_classifier.h5`: LSTM classifier (tumbling windows, J = 3, O = 15000, 400 epochs, seed 4), in the format loaded by TensorFlow 2.15. Generated by `classifier/converterClassificador.py`.
